# Site Podium Flash

Mini-site statique publie par GitHub Pages.

- `index.html` - page d accueil
- `privacy.html` - regles de confidentialite
- `terms.html` - conditions d utilisation
- `style.css` - identite de marque (voir CLAUDE.md du projet)

Les deux pages legales servent a l ecran de consentement OAuth Google
(YouTube Data API v3, habilitation `youtube.upload`).
